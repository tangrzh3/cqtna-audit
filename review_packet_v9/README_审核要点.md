## 2. 怎么复现

**环境**：R ≥ 4.4（本包在 4.4.1 上跑），`cqtna_0.3.0.tar.gz` 随包附上。

```r
install.packages("cqtna_0.3.0.tar.gz", repos = NULL, type = "source")
library(cqtna)
```

**最快的自检**（不需要本项目任何数据，包自带 demo）：

```r
mr <- as_cqtna_mr(cqtna_demo("mr"), build = "GRCh38")
kn <- as_cqtna_known(cqtna_demo("known"), build = "GRCh38")
cqtna_attribution(mr, kn)                       # 应得 4/8，4.96×，P = 0.0048
cqtna_attribution(mr, kn, known_from = "any_record")   # 应得同样的数

mr2 <- as_cqtna_mr(cqtna_demo("mr"), build = "GRCh38",
                   locus_method = "single_linkage")
cqtna_attribution(mr2, kn)                      # 应得 3/7，4.09×，P = 0.028（已发表值）
```

⚠ **第二、三行是本轮的核心对比**：同一份数据、同一个包，**只换分区**，
4.09 → 4.96。若你认为 4.09 才该是主分析，请直接说——那是本轮最大的一个判断。

**表**：包内 `.tsv` 全部是制表符分隔、UTF-8，列名见各文件首行。
`123d_fixed_anchor_full_grid.tsv` 是主网格；`analysis_status` 列直接写明每行的地位
（`prereg_primary` / `prereg_sensitivity` / `posthoc_sensitivity` / `legacy_reproduction`）。

**没有随包附上的**：FinnGen / eQTLGen 原始 sumstats（约 1.5 GB）。
所有位点级结果都可以从随包的 per-record 中间表重算，**不需要原始文件**。

### 第 3 条 · C1 归属口径下 Fisher 检验的分子分母是否真的独立

**事实**：C1 规定"位点的 known 状态由该位点**全部记录**决定"，
背景与显著位点用同一规则打分。这解决了旧口径分子分母不一致的问题
（旧口径：分母全部记录、分子仅显著记录）。

**⚠ 请你查的**：C1 下，**显著位点是背景位点的子集，且用同一批记录判定 known**。
Fisher 精确检验假设的 2×2 表在这种嵌套下是否还有意义？
我在包 README 里写了"Fisher P 是描述性的，不是校准过的 P 值"，
但**正文仍然在引用这些 P 值**。请判断这个免责声明够不够。

### 第 4 条 · 全网格没有做多重比较校正

**我的立场**：网格是"方向一致性"的展示，不是六个独立检验
