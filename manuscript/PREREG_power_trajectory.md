### 2.2 主要与次要指标（预先指定）

### ⚠ 2.2-0 参照名单的定义：一个必须先解决的问题（2026-08-11 发现，在查看任何 R8–R11 数据之前）

以 FinnGen R12 为参照时，其 **FDR<0.05 名单里新位点基因数为 0**——
10 条记录 / 6 个基因**全部**是已知位点（这正是发现①在 FinnGen 轮的原始形态）。
**新位点类别为空，主要指标（已知−新位点）在该阈值下无法计算。**

各阈值下 FinnGen R12 参照名单的构成（用已在手的数据算出，未涉及任何新 release）：

| 阈值 | 记录 | 基因 | 已知位点基因 | 新位点基因 |
|---|---|---|---|---|
| FDR<0.05 | 10 | 6 | 6 | **0** |
| FDR<0.10 | 10 | 6 | 6 | **0** |
| p<1e-3 | 20 | 13 | 8 | 5 |
| **FDR<0.20** | **22** | **14** | **8** | **6** |
| （对照：meta 轮 FDR<0.05） | 21 | 10 | 6 | 4 |

**预先指定的解法（现在定死）**：

- **主要名单 = FDR<0.05**，用于报告整体名单稳定性（这是研究者实际会用的判决规则）；
- **分层对比另用 FDR<0.20 的参照名单**（6 个新位点 + 8 个已知位点，其构成与 meta 轮
  FDR<0.05 名单最接近），并在正文与图注中**明写这是放宽阈值**，
  理由是主阈值下新位点类别为空；
- **"在 5,753 例下没有任何新位点基因达到 FDR<0.05"这一事实本身作为结果报告**，
  不作为分析失败处理。

**★ 顺带得到的一个已观测的验证点**：模拟（以 meta 为参照）预测新位点恢复率在
5,012 例处为 13.4%、6,265 例处为 22.8%；meta 参照名单只有 4 个新位点基因，
故 5,753 例处的期望值不足 1 个基因。**实际观测为 0 个**——与预测一致。
这不是新分析，而是把已有的 FinnGen 轮结果按分层预测重新读了一遍，应写进论文。

### 2.2 主要与次要指标（预先指定）

**主要指标**：在每个 release 上，**已知位点基因的恢复率 − 新位点基因的恢复率**
（参照名单按 2.2-0 定义，分层对比用 FDR<0.20 的 R12 名单）。

选它作主要指标的理由必须记下：release 之间是**嵌套**的（早期 release 的参与者是后期的子集），
嵌套会使两轮名单**本应更相似**，从而抬高所有恢复率的绝对水平；
但该偏倚对两个位点类别的作用方向相同，**差值比绝对水平稳健**。

**次要指标**：
- 每个 release 的检验数、名义 p<0.05 数、FDR<0.05 记录数/基因数/独立位点数
- 各 release 的 FDR<0.05 名单中新位点基因数（预期在整个可观测区间内接近 0）
- 基因层面与**位点层面**的 Jaccard（相邻 release 之间；以及各 release vs 参照 release）
- 各位点类别各自的 recovery 与 retention

### 2.3 ★ 预先登记的定量预测（这是本分析最有价值的部分）

现有模拟能对每个 release 的病例数给出**恢复率的预测区间**。执行顺序必须是：

1. 先把降功效模拟**以 FinnGen R12 为全功效参照**重跑一次（现有代码换个结局即可），
   得到各历史 release 病例数处的预测恢复率与区间；
2. **把预测值写进本文件第 6 节存档**；
3. **然后**才计算真实各 release 的观测恢复率。

⚠ 注意现有校准（meta→FinnGen）用的参照是 meta 名单，与此处不同，**不能直接套用 53a 的数字**。

**预测的方向性偏倚（先写死，避免事后解释）**：模拟的是"同规模的独立研究"，
而真实 release 是嵌套子集，共享个体使真实一致性**高于**模拟预测。因此：
- 观测恢复率 **高于** 预测 → 与嵌套结构一致，不构成对模拟的否定；
- 观测恢复率 **低于** 预测 → 说明真实世界的不稳定性**超过**模拟所示
  （流程变更等额外噪声），这会**加强**而非削弱④a，但须明说模拟因此是下界。

### 2.4 判读表（三种结果，全部预先写明结论）

| 观测到的模式 | 结论 | 论文如何写 |
|---|---|---|
| **A1** 病例数↑ → MR 命中↑；新位点 Jaccard 持续低；已知位点 recovery 高且早期即达平台；候选成分持续改变 | 解释 (2)（数据集异质性）被显著削弱 | ④a 升级为"在同一 GWAS 资源随功效自然增长的纵向过程中可直接观察到" |
| **A2** 轨迹整体稳定，新位点名单在各 release 间高度一致 | **④a 被削弱**：FinnGen vs meta 的翻转主要来自数据集异质性而非功效 | **如实报告，并下调④a 的表述**至"两个不同来源的结局 GWAS 给出不重叠的名单，其中数据集差异与功效的贡献无法分离"。Fig 4 的模拟仍成立但须注明缺少真实世界纵向支持 |
| **A3** 无单调趋势／各 release 之间无规律 | 无结论 | 报告为"该资源的 release 结构不足以分离功效"，不解释为任一方向的证据 |

**A2 是可能的，且我们事先接受它。** 本项目的纪律是"阴性之后不得另起炉灶找阳性"——
若出现 A2，**不得**改用别的资源再试一次以求得到 A1。

### 2.5 过程阳性对照（不通过则该分析作废，不解释结果）

1. **重现校验**：本轨迹中 FinnGen R12 那一轮必须**逐位重现**主分析已有的数字
   （严格集 3,579 条、FDR<0.05 = 10 条、以及那 10 条的基因与 profile）。对不上先查流程，不看趋势。
2. **单调性**：MR 命中数与病例数的 Spearman ρ 应 > 0。若为负或无关，说明各 release 的
   处理不可比，先查流程。
3. **已知位点的早期出现**：MC1R/PARP1 一类大效应位点应在最早的可用 release 即出现。
   若连它们都不稳定，说明流程在跨 release 应用中有问题，而不是发现了新东西。

### 2.6 不会下的结论

- 不会说"唯一变化的是功效"（见 2.0 闸门）
- 不会对只有 4 个新位点基因、6 个已知位点基因的分类差异做**正式显著性检验**；

- 不会把相邻 release 之间的 Jaccard 当作独立观测（嵌套）

## 3. 分析 B：多信号敏感性（只用于保卫④b）

### 3.0 设计修订（2026-08-11，第 0 步核实资源后；未看任何分析结果）

第 0 步发现 FinnGen 公开了两样东西，使原设计的主要技术障碍在**结局侧**消失：

| 资源 | 内容 | 对本分析的意义 |
|---|---|---|
| `finemap/full/susie/finngen_R12_C3_MELANOMA_SKIN_EXALLC.SUSIE.{cred,snp}.bgz` | FinnGen 自己用**样本内 LD** 做的 SuSiE 精细定位：credible set 与逐 SNP PIP（tabix 索引） | 结局侧的"有几个独立信号"**已经有权威答案**，无需我们用 1000G 代理重跑 |
| `ld_matrix/finngen_r12_chr*_ld.tsv.gz`（每染色体约 10 GB，tabix 索引） | FinnGen R12 的**样本内 LD 矩阵** | 结局侧可正确运行 `susie_rss`／`coloc.susie`，不再受 LD 失配困扰；按区间抽取即可，不必下载全量 |

**仍然不变的约束**：eQTL 侧 n=85–100 且无个体数据、无样本内 LD，
其 SuSiE 结果依旧不可靠。**这是本分析的硬边界，不因上述资源而改变。**

**★ 由此得到一个更强也更便宜的主论证（本节的核心）**：

> 两轮之间，**暴露侧数据完全相同**。因此④b 中 H3/H4 的任何变化，
> 其来源必然在结局侧。

于是主检验变为：**在每个功效水平上，结局侧在该区域有几个独立信号？**
若某区域在两个功效下**结局侧都只有一个可信信号**，则"结局侧多信号未被建模"
不能解释该区域的 H3/H4 移动。

⚠ **不可过度声称**：eQTL 侧若本身有多个因果信号（该结构在两轮间恒定），
仍可能在模型误设下与变化的结局功效发生交互，从而产生 H3/H4 移动。
所以上述论证**收窄**而非**关闭**替代解释 (1)。这句必须随结果同行。

**另一个连带的、本身就有信息量的观察**：FinnGen 只对达到显著性阈值的区域做精细定位。
我们的候选区域多数**根本不会被精细定位**。这一事实本身支持"分辨力受功效限制"的读法——
在这些功效下，驱动候选名单的区域连 fine-mapping 都做不了。

### 3.1 修订后的工具与顺序

1. **FinnGen 官方 SuSiE credible set（主）**：读取各 release 的 `.SUSIE.cred`，
   统计目标区域的可信信号数与 PIP 分布。第 0 步须确认 R8–R11 是否同样提供该产品。
2. **COJO（次）**：用于 FinnGen 未做精细定位的区域，以及作为 1 的交叉校验。
3. **`coloc.susie`（辅，仅结局侧用样本内 LD）**：在 1 或 2 提示 ≥2 个独立信号的区域运行；
   **必须报告 eQTL 侧的 LD 失配诊断**，且其阴性不得单独作为"未推翻结论"的证据。
4. **信号特异的 coloc**：对多信号区域，按 credible set 逐信号做共定位。

**★ 与分析 A 合流**：既然 R8–R12 每一版都有自己的样本内资源，
分析 B **同样在 FinnGen release 家族内运行**（而非 FinnGen vs meta）。
两个分析共用一个设计，且都彻底避开跨数据集混杂。meta 轮的多信号分析因缺乏样本内 LD
而不做，此限制须写明。

### 3.2 目标位点（预先固定，不得事后增删）

| 位点 | 为何入选 |
|---|---|
| **PARP1** | ④b 的假阳性案例（0.92→0.05） |
| **ZFYVE19** | ④b 的假阴性案例（→0.99） |
| **MC1R 簇**（VPS9D1-AS1、CDK10、SPATA33、CHMP1A、CTU2） | 发现①②的核心；**同时是分析 B 的阳性对照，见 3.4** |

### 3.3 LD 失配诊断与判废条件（跑之前写死）

每次 `susie_rss` 必须报告：`estimate_s`（LD 与 z 的失配度）、credible set 数、
各 credible set 的 purity、收敛状态。

**判废**：若某一侧（尤其 eQTL 侧）的 `estimate_s` 超出可接受范围或 credible set purity 低，
该位点的 SuSiE 结果记为**不可用**，不得作为"未推翻结论"的证据。

### 3.4 ★ 阳性对照（决定分析 B 是否有分辨力）

**MC1R 区域已知存在多个独立功能变异**（R151C、R160W、D294H 等）。
因此：在 meta 结局下，COJO 必须在 MC1R 区域检出 **≥2 个独立信号**。

- 若检出 ≥2 → 方法在本数据上有分辨多信号的能力，其余位点的结果可解释；
- **若 MC1R 只检出 1 个信号 → 分析 B 在本数据上无分辨力，全部结果记为无信息**，
  按本项目纪律（阳性对照失效即废掉该检验）处理，

### 9.1 阳性对照：通过了登记的判据，但登记的判据太松
