## 1. ⚠ 先说这一节**不能**说明什么

本文刚刚在自己身上犯过一次 absence-of-evidence 的错（把 p=0.079 的阴性当成支持，
见 S12 §3 末）。同一个错在文献审计里更容易犯，因此先把边界写死：

1. **摘要只用来判定纳入，不用于评分。** 摘要约 250 词，没有人会在里面写位点归属。
   若用摘要判"这个领域不做某检查"，即为同一类错误。
2. **一切实践性判断只在能拿到的全文上做**，分母永远是全文集，不是检索集。
3. **正则匹配只能证明"文中有没有这句话"**，不能证明作者有没有做这件事。
   假阴性（做了但没用我们的措辞）与假阳性（有措辞但没真做）都可能。
   §4 给出一次假阴性抽检。
4. 全文来源为 **PMC 开放获取子集**，可能与非开放获取论文不同。

## 3. 评分判据（在读任何全文之前写死）与结果

| 判据 | 问的是什么 |
|---|---|
| **C1 已知位点归属** | 有没有把自己的显著信号与**该结局自身**先前报告过的位点做比较 |
| **C2 共定位** | 做没做共定位 |
| **C3 结局依赖/名单稳定性** | 有没有报告候选名单如何依赖所用结局 GWAS 或其功效 |
| **C4 工具变量数披露** | 有没有说明每个 exposure 用了几个工具变量 |
| **C5 SMR/HEIDI** | 有没有用 SMR/HEIDI |

**结果（n = 152 篇全文）**：

| 判据 | 严格模式 | 放宽模式（事后，见下） |
|---|---|---|
| **C1 已知位点归属** | **2 / 152 = 1.3%** | **12 / 152 = 7.9%** |
| C2 共定位 | 90 / 152 = 59.2% | 91 / 152 = 59.9% |
| **C3 结局依赖 / 名单稳定性** | **1 / 152 = 0.7%** | 54 / 152 = 35.5%＊ |
| C4 工具变量数披露 | 69 / 152 = 45.4% | 72 / 152 = 47.4% |
| C5 SMR/HEIDI | 72 / 152 = 47.4% | 74 / 152 = 48.7% |

＊ C3 的放宽模式把 "statistical power / power calculation" 这类**泛泛提到功效**
的论文也算进来，因此 35.5% **不是**"报告了名单对结局的依赖"。
问到本文所指的那件事时，答案是 **1 / 152**。正文引用严格值并注明这一区别。

**既做共定位、又做已知位点归属的：10 / 152。**
**既不做位点归属、也不做名单稳定性的：139 / 152 = 91.4%。**

### 两处必须一并披露的过程问题

**(a) 一个 bug。** 首轮评分把全文小写化后，却用含大写字面量的正则匹配
（`\bSMR\b`、`\bSuSiE\b`、`\bPP\.?H4\b`、`\beCAVIAR\b`），这些**永远不可能命中**，
导致 C5 报出 0/152——这个数字在本文献里不可能成立，正是它暴露了 bug。
已改为对原文大小写不敏感匹配。**这是修错，不是调参。**

**(b) 一次事后放宽。** 看过首轮结果之后，我们把 C1 与 C3 的模式放宽，
以捕捉预设模式会漏掉的写法（"previously associated loci"、"already known"、
"varying the outcome" 等）。**这发生在看到结果之后，属事后**，因此作为**单独一列**
报告而不是替换严格值。正文引用**放宽值**（对文献更宽容的那个），
因为本节的主张是"这些检查很少见"，宽容的分母使该主张**更难**成立而非更易。

## 4. 假阴性抽检（人工）

从 140 篇 C1（放宽）判为 0 的论文中随机抽 8 篇，人工检查全文中每一处
"locus / loci" 的上下文：

- **2 篇全文根本没有出现 locus/loci**
- 其余 6 篇中，该词**只出现在** "expression quantitative trait locus" 这个术语内，
  或出现在参考文献标题里（如 "…reveals a new susceptibility locus at 5q12.3"）

→ 抽检未发现系统性假阴性。8 篇中 **0 篇**实际做了与自身结局已知位点的比较。

## 5. 结论，以及它的边界

> 在 152 篇用 eQTL 工具变量做靶点提名的论文中，**至多 12 篇（7.9%）**
> 把显著信号与该结局自身已知的位点做过比较，**1 篇（0.7%）**报告过候选名单
> 对所用结局 GWAS 的依赖。约 60% 做了共定位，约 47% 用了 SMR/HEIDI。

**这支持的主张**：本文 §4.5 提出的两条最便宜的检查（①位点归属、③④名单的结局依赖）
在当前实践中**确实罕见**，因此把它们写成规范建议不是在批评三篇论文的疏忽，
而是指出一个近乎普遍的空白。

**这不支持的主张**：
- 不能推出这 152 篇的结论是错的——**没做某项检查 ≠ 结论不成立**
- 不能推出做了检查的那 10–12 篇就是对的
- 不能外推到非开放获取文献，或 PubMed 未收录的文献
- 期刊分布偏向中小型刊物（Medicine 11 篇、Discover Oncology 9 篇、
  J Transl Med 7 篇、Front Immunol 6 篇），高影响力刊物样本很少，
  **不能代表该框架在顶级期刊中的实践**

## 6. 与 S16 的关系

S16（三篇同框架研究的逐项对照）**保留**：它做的是深度对照——逐条证据、
逐个数字地比，能看到本文与它们在同一问题上的具体差异。
本节做的是广度：用检索定义的样本回答"这是不是普遍现象"。
两者互补，**不得互相替代**：S16 的 n = 3 不能证明普遍性，本节的正则匹配不能证明质量。
