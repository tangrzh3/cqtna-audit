# S51：恒等式在被审计文献里覆盖多大范围

**编号**：S51　**日期**：2026-08-25
**脚本**：`step151_instrument_count_in_literature.py`
**输出**：`151a_estimator_usage.tsv`、`151b_console.log`
**语料**：与 S23 文献审计同一批缓存全文（`litaudit/` + `105a_research_cache/fulltext/`），
共 **154** 篇。

⚠ **状态**：事后分析，回应第四方评审。它不改动任何注册终点。

---

## 1. 为什么要量这个

针对本文中心主张最有力的一条反驳是：

> 恒等式只对**单工具 Wald 比**成立；有能力的研究用 IVW 或 weighted median，
> 因此你打击的靶子很小。

这是一个**关于文献的经验主张**，而不是关于代数的主张。它可以直接量，
而我们手上正好有那 154 篇全文。**我们直到被第四次质疑才想到去量它**
（方法论纪律 §五-63）。

## 2. 计什么

对每篇缓存全文做词组匹配，记录两类事实：

| 字段 | 匹配的意思 | 正则要点 |
|---|---|---|
| `wald` | 文中点名 Wald 比 | `wald('s)? (ratio|estimat|method)` |
| `ivw` / `wmedian` / `egger` / `mode` | 点名任一多工具估计量 | `IVW`、`inverse-variance weight`、`weighted median`、`MR-Egger`、`weighted mode` |
| `single` | 文中任何位置声明其 cis 工具是**单个变异** | `single-(SNP|variant|instrument)`、`only one (SNP|variant|instrument)`、`one (SNP|variant) per/for each`、`a single cis-eQTL`、`top cis-eQTL` |
| `cis` | 提到 cis-eQTL / cis-QTL | `cis[- ]eQTL`、`cis[- ]QTL` |

一篇论文可以同时命中多项，这不是矛盾：**在 trans 或放宽工具集上跑 IVW、
同时 cis 提名只用一个变异，是这个领域里常见的组合。**

## 3. 结果（`151b`）

154 篇全文，其中 **85 篇**提到 cis-eQTL / cis-QTL。

**点名过某估计量（全文任何位置）**

| 估计量 | 篇数 / 154 | 占比 |
|---|---:|---:|
| IVW | 129 | 84% |
| MR-Egger | 111 | 72% |
| weighted median | 104 | 68% |
| mode-based | 73 | 47% |
| Wald ratio | 68 | 44% |

**关键的四个数**

| | 篇数 | 占 154 |
|---|---:|---:|
| 声明 cis 工具是单变异 | **71** | **46%** |
| 点名任一多工具估计量 | **130** | **84%** |
| 只点名 Wald、无任何多工具估计量 | 3 | 2% |
| 本扫描认不出任何估计量 | 21 | 14% |

**两者不是互补的**：点名多工具估计量的 130 篇里，**65 篇同时声明其 cis 工具是单变异**。
把范围限制在真正谈 cis-eQTL 的 85 篇上，**48 篇（56%）声明单变异 cis 工具**，
其中 45 篇同时点名了某个多工具估计量。

## 4. ⚠ 这组数字**不是**比率

这是本节最重要的一段，正文必须照抄其性质：

1. **46% 是覆盖面的下界**，不是"46% 的论文适用"。
   一篇论文可能只在补充表里给出每基因的工具数，正文根本不写这句话——
   词组匹配看不见，于是被计为阴性。
2. **84% 是逃脱者的上界**，不是"84% 的论文不适用"。
   点名 IVW **不等于** cis 提名名单是 IVW 产出的：上面那 65 篇就是反例。
3. **词组匹配说不出一篇论文用哪个估计量产出了候选名单**，
   而这恰恰是唯一要紧的问题。要回答它必须逐篇读方法与补充表，本节没做。
4. 语料是 **PMC 开放获取子集**，与 S23 同一批，继承 S23 的全部边界
   （见 `SUPP_literature_audit.md` §1）。
5. 21 篇认不出估计量的论文既可能在覆盖面内也可能在外，本节不作分配。

**能安全说出口的只有一句**：这个领域里，宣称单变异 cis 工具的论文**不是边缘现象**，
而点名 IVW 也**不能**把一篇论文排除在恒等式之外。**范围的确切大小仍未知。**

## 5. 复现

```
python step151_instrument_count_in_literature.py <repo>
```

约 1 秒，无外部依赖，无随机性。
