# S51：恒等式在被审计文献里覆盖多大范围——一次失败的测量，与替代它的设计

**编号**：S51　**日期**：2026-08-25，**2026-08-26 大幅改写**
**脚本**：`step151_instrument_count_in_literature.py`（词组扫描）·
`step156_estimator_provenance_coding.py`（C6 人工编码）
**输出**：`151a_estimator_usage.tsv`、`151b_console.log`、
`156a`/`156b`（盲编码文件）、`156c`–`156e`（一致性与裁定）
**语料**：与 S23 同一批缓存全文，共 **154** 篇

---

## 0. ⚠ 撤回声明（本节最重要）

本文件 2026-08-25 的第一版写着：

> 71 篇（46%）是恒等式**覆盖面的下界**，130 篇（84%）是**逃脱者的上界**。

**这两句都是错的，现予撤回。** 它们不是"过于自信的表述"，而是**把一个方向未知的
词组命中数说成了有向的界**。第三方复核指出了这一点，核查后问题比复核者说的更重。

---

## 1. 为什么错

`step151` 的 `single` 正则在**全文任意位置**匹配。它不要求该词组：

- 与 `cis-eQTL` 出现在同一句或同一段；
- 描述的是**主要候选名单**；
- 描述的是 **Wald 估计**；
- 属于作者正在做的那一支 cis 提名分析。

**复核者点名的反例成立**：`PMC11187347` 的记录是 `cis=0, single=1`
——一篇**通篇不提 cis-eQTL** 的论文，被计进了"声明单变异 cis 工具"。

### 命中数在最低限度的邻近性要求下崩塌

| 口径 | 篇数 |
|---|---:|
| 词组出现在全文任意位置 | **71** |
| ……其中**从不提及 cis-eQTL** | **23** |
| 词组与 cis 提及相距 500 字符以内 | **13** |
| 词组与 cis 提及**同句** | **10** |

**71 → 10，七倍。** 一个在如此弱的约束下就掉掉七分之六的计数，
不是下界也不是上界，而是**方向未知的词组命中数**：

- 它可能**虚高**——"single-cell"、"single-variant analysis"等无关表述会命中；
- 它也可能**虚低**——每基因工具数只写在补充表里的论文完全看不见。

同理，"130 篇点名多工具估计量"与"其中 65 篇也命中 single"**说明不了**
这些论文的 cis 候选名单由哪种估计量产生。点名 IVW 可以只是因为在 trans 上跑了 IVW。

## 2. ⚠ 现在能说什么

**只有一句**：这个语料里，估计量的**措辞**分布如下（`151a`），
且这组数只作为**语料描述**，不作为任何比例的估计。

| 估计量（全文任意位置点名） | 篇数 / 154 |
|---|---:|
| IVW | 129 |
| MR-Egger | 111 |
| weighted median | 104 |
| mode-based | 73 |
| Wald ratio | 68 |

**恒等式在这个文献里覆盖多大范围，目前是未测量的。**
正文按此措辞，不再声称任何界。

## 3. 替代设计：C6

要回答的量只有一个：

> **这篇论文的主要 cis 提名名单，是由哪种估计量产出的？**

它无法由词组匹配得到，只能逐篇读方法与补充表。设计如下（规则见
`156_C6_CODING_RULES.txt`，**写于任何论文被读之前**）：

| 项 | 取值 |
|---|---|
| 样本 | **与 C1/C3 同一批固定种子 46 篇子样本**（不另抽，便于与审计其余判据对照）|
| 分类 | `W` 单变异 Wald · `M` 多工具估计量 · `X` 混合流程 · `U` 无法确定 |
| 编码者 | 两人**独立**，互不可见，且**都看不到 `step151` 的自动结果** |
| 盲化 | 两份文件用不同种子打乱行序（1561 / 1562）|
| 证据 | 每一条非 `U` 判定**必须**附上所依据的原句与其位置；无引文者在裁定时按 `U` 处理 |
| 报告 | 原始一致率、**裁定前** Cohen's κ、裁定后分布、`W` 在可确定集（W+M+X）中的 Wilson 区间 |
| `U` | **单独报告，不做再分配**——报告缺失本身就是关于这个文献的发现 |

⚠ **κ 在裁定前计算**，且与原始一致率并列报告：四分类且很可能有一个占优类别，
κ 会因流行度效应塌向 0 而一致率仍很高——C1 已经发生过一次这种情形（S23）。

⚠ **`U` 是真答案不是失败。** 规则明写：不得从期刊、年份、作者或论文"看起来
是否高级"去猜。

## 4. 这一节留给读者的教训

我们对文献提出的其中一条要求，是**别把自动匹配的命中数当成实践的测量**
（S23 §1 早已写死这条边界，并因此对 C1/C3 做了 precision 校正）。
**然后我们在 S51 上违反了自己这条规则**，而且是在论文最关键的一处主张上。

抓到它的是第三方复核，不是我们的任何一个审计脚本——
`step127` 只查数字，而这里的每个数字都对得上表，
**错的是那些数字被称作什么**。
