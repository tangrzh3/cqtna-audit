## 1. 问题

模块 H（S42）把八个显著 bounded locus 分成三个"结局 GWAS 自身已达 5×10⁻⁸"和
五个未达的，并显示剔除前者后富集消失。**独立地问一次**：
这两组在结局侧各有几个**可分辨**的信号？

`step60a–c` 只做过四个区，且是为另一个问题挑的。本节补齐其余四个
（SMC2、KANSL1、MDM4、KIAA0040，**全部属于亚阈值组**），
约定完全不变：500 kb 半窗、同一批 1000G EUR 525 人、同一条 plink2 调用。

## 3. ⚠ 这条证据能走多远

**亚阈值位点给出 0 个 credible set 是预期之内的**——精细定位本来就需要强信号。
因此本节**与模块 H 的分解一致，但不是它的独立证据**，
**不得读成"已证明亚阈值部分为空"**。这句话写在 `step147` 的脚本头，先于结果。

## 4. ★★ "1 个 credible set" 这句话不足以描述结果

KANSL1 按判据是"1 个、可采信"。但看内容：

| | credible set 数 | 变异数 | 跨度 |
|---|---:|---:|---:|
| PARP1 | 1 | **35** | **68 kb** |
| KANSL1 | 1 | **1,851** | **650 kb** |

KANSL1 位于 **17q21.31 倒位区**，那 1,851 个变异是**倒位单体型整块在动**，
**它没有定位到任何东西**。两者在"1 个 credible set"这句话里完全无法区分。

**➜ 报告 credible set 时必须同时报其大小与跨度。** `147a` 已增列。

## 5. ★★ 代理 LD 精细定位在这份数据上有两种失效模式，第二种不报错

### 5.1 强信号处：虚假分裂（已知）

MC1R：本流程给 **9–10 个** credible set（L = 20 时 12–19 个，**从未饱和**），
而 FinnGen 官方用**样本内 LD** 的答案是 **3 个**。`estimate_s` 高达 0.216 / 0.333，
其余区仅 0.012–0.089。**且 meta 那次拟合未收敛。**

### 5.2 弱信号处：结果依赖随机种子（此前未记录）

`susie_get_cs` 对大 credible set 的 purity 用**随机抽 100 个变异**估计。
一个变异数很多、purity 恰在阈值附近的 set，**会因抽样而时进时出**。

无种子连跑三次 KANSL1：**0 / 1 / 0**。三次都 `converged = TRUE`、`niter = 2`——
**不是收敛失败，不报错，不告警。** `set.seed(1)` 后 4/4 稳定。

固定种子后跨 5 个种子重测（`147a` 的 `n_cs_across_seeds` 列）：

| 区域 | 结局 | 跨种子的 credible set 数 | 稳定 |
|---|---|---|:---:|
| **KANSL1** | **FinnGen** | **0, 0, 1, 1, 1** | **否** |
| KANSL1 | meta | 1, 1, 1, 1, 1 | 是 |
| 其余全部 | 两者 | 各自恒定 | 是 |

⚠ **可复现 ≠ 稳健。** 加种子让 KANSL1 可复现，但它的取值仍取决于选哪个种子。

⚠ **打印的汇总只列 meta 行**，所以 KANSL1 在 FinnGen 上的种子不稳定
**只出现在 `147a` 表里、不出现在汇总里**。读表，不要读汇总。

## 6. 对正文的建议

正文现在把这件事写成 "external-LD SuSiE attempt failed by over-splitting"，
只讲了 §5.1。**完整版更强，也更贴本文主题**：

> 代理 LD 精细定位在这份数据上有两种失效模式。强信号处虚假分裂——
> MC1R 得到 9–19 个 credible set，而样本内 LD 的答案是 3 个。
> 弱信号处结果依赖随机种子——KANSL1 在无种子重复运行中给出 0、1、0 个
> credible set，每次都报告收敛，不产生任何警告。第二种更隐蔽，
> 因为流程不会告诉你它发生了。
