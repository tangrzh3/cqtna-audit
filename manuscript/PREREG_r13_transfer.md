## 0. 这一份检验的是什么，以及**它不是什么**

### 0.1 它不是第六个功效点

`PREREG_power_trajectory.md`（S9）的第 0 步闸门写死了一条：
**只有 endpoint 定义逐字可比的 release 才能进入功效轨迹**。
R6 正是被这条挡掉的（143 例 vs R8 的 2,705 例，说明尚未接入癌症登记链接）。

R13 **不满足这条闸门**：

| | R12（全文所用）| R13 |
|---|---|---|
| endpoint | `C3_MELANOMA_SKIN_EXALLC` | `C3_MELANOMA_SKIN_WIDE` |
| 病例 / 对照 | 5,753 / 378,749 | 6,226 / 372,159 |
| 疾病编码 | C43 · 172 · C44 + melanoma morphology | **相同** |
| controls 排除 | C3_CANCER + C3_CANCER_WIDE_EXALLC | C3_CANCER + **C3_CANCER_WIDE** |

**病例定义相同，controls 排除规则不同。** 故 R13 **不得**作为 R8→R12 轨迹的第六点，
**不得**进入 `59a_release_trajectory.tsv` 的符号检验或与 `58a` 登记预测的区间比对。

⚠ 上表的 endpoint 定义**不是从 manifest 的描述行推断的**。
R13 manifest 把该 endpoint 的 phenotype 字段写作 "Malignant melanoma of skin, **including Hilmo**"
（Hilmo = 芬兰住院登记），照字面读会得出"R13 新纳入了住院登记病例"的结论。
**那是错的**：Risteys 的逐项编码核对显示 R12 的 `_EXALLC` 本来就含住院编码。
（Step 98 曾按 manifest 字面推断出"病例口径变了"，已更正；见纪律第 17 条。）

**不得改用裸 `C3_MELANOMA_SKIN`**：R13 把它列为更窄的相似 endpoint，
且已发布的 manifest 里根本没有该 endpoint。本地核实：`_EXALLC` 后缀在整个 R13 manifest
出现 **0 次**，即 R12 所用的 endpoint 在 R13 已不存在，没有"同名续跑"这条路。

## 1. ★ 功效与定义两者同时变了 —— 事先写死的处理

这是本预注册最关键的一节。R13 相对 R12 有**两处**变化，公开数据**无法把它们分开**，
本测试也**不声称**能分开。但两者的**方向**可以事先判定：

| 变化 | 量 | 对"信号更强/更多"的方向 |
|---|---|---|
| 病例数 | 5,753 → 6,226（**+473，+8.2%**）| **↑**（无歧义）|
| 对照数 | 378,749 → 372,159（**−6,590，−1.7%**）| **≈0**。N_eff 由病例数主导：R13 的 `1/n_controls` 项只占 `1/n_cases + 1/n_controls` 的 **1.6%** |
| controls 排除规则 | `C3_CANCER_WIDE_EXALLC` → `C3_CANCER_WIDE` | **↑ 或 ≈0**。队列总量在增长而对照池反而缩小 → 排除规则**变宽**了 → 对照中残留的癌症患者更少 → 结局错分更少 → 效应估计的衰减更小 |

→ **三项要么把结果推向"更强/更多"，要么可忽略；没有一项把结果推向"更弱/更少"。**

**由此得到一条不对称的事先判读（本节的核心）**：

- **若转移成功**（结论不变或略增强）：**部分被混杂**。不得写成"功效增长导致"，
  也不得写成"定义变化导致"，只能写"在同资源的当前发布上结论不变"。
- **若转移失败**（结论方向反转或消失）：**两处变化都解释不了它**，因为两者都指向反方向。
  失败是**真信息**，必须原样写入正文与摘要。

⚠ **纪律第 9 条在此明确适用**：若结果与 R8–R12 轨迹的外推不符，
**不允许**归因于"endpoint 定义变了"作为开脱。上表已事先说明为什么这个开脱不成立。

### 10.4 ★ 必须与"六项全部符合"一并报告的四条

**1. P1 的点预测没中，中的是区间下沿。**
登记点值 11（外推 +1），观测 **10 = 与 R12 完全相同**。
即 **N_eff 增加 8.1% 换来 0 条新记录**。这与 R8→R12 的斜率一致
（R11→R12 的 N_eff 增加 46% 才换来 2 条），但必须写明预测的**方向**未兑现，
只是幅度落在事先留的余地内。**不得**把"落在区间内"写成"预测准确"。

**2. C1 与 C3 的倍数和 P 在 R12 与 R13 之间逐位相同，这是算术，不是稳定性证据。**
两格都是"2 个显著位点、2 个都已知、背景不变"，而 Fisher P 只依赖那张 2×2 表。
**同一张表必然给同一个 P。** 这一行看起来像脚本 bug，实际不是；
但它**不构成**第二次独立确认，只说明位点计数没变。
（作者本人在初次读结果时先怀疑是 bug，核对后确认不是——见 10.5。）

**3. 名单的稳定不是数据没变造成的。** 3,434 条记录的 z 值**没有一条相同**
（0/3,434），|z| 的相关系数为 **0.937**，se 的中位比值为 **0.9615**
——与 N_eff 增加 8.1% 所预期的 1/√1.081 = 0.962 **几乎完全吻合**，
即 R13 确实是一份功效更高的独立计算，而不是 R12 的副本。
**在底层统计量全部改变的情况下，FDR<0.05 名单逐字不变。**
这是本次最强的单一观测。

**4. 名义层面churn 很大，只是恰好数量相同。**
名义 p<0.05 的记录数 R12 与 R13 **都是 275**，但两个集合**只共享 224 条**
（Jaccard **0.687**），各有 **51 条（19%）**是对方没有的。
→ **275 = 275 是巧合，不是同一批记录。**
阈下层面一次发布就换掉近五分之一，而阈上层面纹丝不动
——与全文"功效决定名单、已知位点部分稳定、新位点部分脆弱"的结构一致。
按 R13 的 FDR 排序，第 7–13 名依次为 GSTM4 (0.134)、XBP1 (0.139)、CLDN7 (0.139)、
PADI4 (0.154)、HLA-C (0.193)、FADS1 (0.193)、CRHR1 (0.193)，
其中多数属新位点类别，**无一达到显著**。最接近的 GSTM4 由 FDR 0.295 → 0.134
（p 0.0042 → 0.00055），是本次唯一一次明显的向上移动，仍差一个数量级。
