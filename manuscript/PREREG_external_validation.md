# S40：外部独立验证——采纳记录与冻结设计

**编号**：S40
**采纳日期**：2026-08-20
**状态**：⚠ **已采纳，但尚未构成"预注册"**——见 §3。
**基准文本**：`EXTERNAL_VALIDATION_PROTOCOL_v9_3.md`（第三方复核者起草，**未经本项目改写**）

---

## 0. 这份文件是什么，不是什么

**是**：本项目正式采纳那份外部验证方案的**记录**——采纳了什么、何时采纳、
采纳后受哪些约束、以及在什么条件下它才升格为真正的预注册。

**不是**：不是那份方案的替代品，也不是它的改写版。
方案正文仍在 `EXTERNAL_VALIDATION_PROTOCOL_v9_3.md`，**逐字保留第三方起草的样子**。

### 为什么分成两份文件

因为本项目已经因为混淆"谁在什么时候写下什么"栽过两次：
把事后稳健性分析标成预注册（S33 那次），
把无法由 git 证明先后的分析称作预注册（S39 那次）。

**如果把第三方的方案就地改成"我们的预注册"，第三个同类错误就会发生**——
文件会显示 2026-08-20 有一份完整的、写得很好的预注册，
而看不出它的设计是别人做的、且是在看完我们全部结果之后做的。

所以：**方案是收到的（他人、事后）；采纳是我们做的（本项目、有日期）。两件事分开记。**

## 1. 采纳了什么

`EXTERNAL_VALIDATION_PROTOCOL_v9_3.md` 的**全部** §1–§10，无保留、无修改。
其中本项目认为最要紧的六条，摘录于此以便本文件自足：

| # | 冻结项 |
|---|---|
| **1.1** | **确证性问题只有一条**：在一个 outcome 独立的队列里，冻结的 CD4⁺ T 细胞 cis-eQTL 工具产生的候选名单，是否再次集中于**在接触 outcome 之前即已知**的黑色素瘤位点 |
| **1.2** | **明确排除**：CD4 细胞特异性、其他祖源、其他细胞类型、自身免疫疾病、患者疗效分层、因果基因归属。**RA 不进入确证性终点** |
| **1.3** | **独立性按队列谱系判定，不按发表年份**。须与 FinnGen R12/R13、Rashkin GCST90011809 及 Landi 参照名单的全部贡献队列**无 participant 重叠**，并取得数据保管方签署的重叠表 |
| **1.4** | **分析口径沿用 v9.3 冻结值**：`fixed_centre`、`locus_kb = 1000`、C1 `any_record`、randomized-greedy matching、tolerance 1.00、10,000 次置换 + 完整容差扫描 |
| **1.5** | **四份错配疾病名单全部事前冻结**，不得事后挑选最有利对照（这一条直接来自 S39 的教训）|
| **1.6** | **判读三分**：主检验失败且信息充分 → **negative**；错配对照也富集 → **void**；样本量/覆盖率/有效位点不足 → **inconclusive**。三者不得混用 |

**主要成功标准六条**（方案 §6）同样整体采纳，不逐条重述。

## 2. 采纳之后本项目受什么约束

1. **不得**在拿到验证结果之后修改 §1 的任何一项，也不得增删成功标准；
2. **不得**用次要分析（已知/新位点运输、Jaccard、效应校准、外部 colocalisation）
   挽救失败的主终点——方案 §8 明写，本项目接受；
3. **不得**把 FinnGen DF13 当作外部验证。它是同一参与者基础上的延长随访，
   只能称 transfer test；
4. **不得**因为某个 melanoma meta 更新、编号更大就视其为独立——
   须先做队列谱系排查并取非重叠子集；
5. **HCC 可作为第二阶段独立验证**，但不与第一阶段合并判读。

## 3. ⚠ 为什么现在还不是"预注册"

采纳 ≠ 预注册。方案要成为可主张的预注册，还差三件事，**目前一件都没有**：

| 前提 | 状态 |
|---|---|
| **合格的外部队列** | **没有**。§1.3 的无重叠要求 + 保管方签署的谱系表，一样都还没有 |
| **公开注册并取得 DOI**（OSF / Registered Report） | **没有** |
| **锁定容器与清单**（`renv.lock`、CQTNA tarball、工具表、名单、SHA-256 清单）在收到任何外部关联统计之前存放 | **没有** |

**因此本文件目前的效力仅限于：本项目已承诺按此设计执行，且承诺不再更改设计。**

⚠ **在拿到 DOI 之前，正文与任何对外材料都不得称本方案为 "pre-registered"**，
只能称 "a validation protocol has been specified and adopted"。
**这条限制的存在理由，就是本项目前两次踩过的坑。**

## 4. 正文可以怎么写（现在）

> An external validation protocol has been adopted and its design frozen
> (Supplementary S40), restricting the confirmatory question to the melanoma
> outcome-side claim in a cohort with no participant overlap with any dataset
> used here. It has not yet been registered and no qualifying cohort has been
> secured, so it carries no realised statistical power and is reported as a
> commitment rather than as evidence.

⚠ **不得**写成 "we will validate"、"validation is underway" 或任何暗示已有数据的说法。

## 5. 采纳的理由（记录下来，便于日后复核）

三轮复核一致指出：内部统计证据已基本通过，**真正限制稿件档次的是缺少独立外部验证**。
本项目同意这个判断。

采纳这份**由复核者起草**的方案，而不是自己另写一份，理由有二：

1. **它由没有看过我们中间过程、但看过我们全部结果的人写成**，
   因而更可能划出我们自己看不见的边界——例如它把确证性问题
   收窄到 outcome 侧一条，而我们自己写大概率会想把 CD4 特异性一并塞进去；
2. **它对独立性的判据（队列谱系而非发表年份）比我们原来的想法严**。
   我们此前默认"新的 meta 就算外部"，方案指出那是错的。

⚠ 反过来说：**采纳一份别人写的方案，不会让它变成"事前"的**。
它写于 v9.3 之后，作者看过全部结果。它的价值在于**约束未来**，不在于追认过去。
