# 预注册：密度匹配置换的估计目标

**日期**：2026-08-18 · **状态**：草案，**在看任何新结果之前必须定稿**
**缘由**：第三方复核指出，现有两套置换实现的匹配规则不同，且**显著与否会被
一个未经事先论证的参数翻转**。在把任一 P 值写进正文之前，必须先冻结估计目标。

---

## 0. 为什么需要这份文件

同一份 CD4 数据，固定 seed 与置换次数，**只改匹配容差**：

| 容差 | 倍数 | 经验 P | 匹配覆盖率 |
|---:|---:|---:|---:|
| 0.10 | — | **NA** | 43%（不合格） |
| 0.25 | — | **NA** | 86%（不合格） |
| 0.50 | 4.56 | 0.022 | 100% |
| 1.00 | 3.49 | 0.042 | 100% |
| 2.00 | 3.58 | 0.040 | 100% |

⚠ 上表是**修好之后**的。修好之前，容差 0.25 会在 1/7 位点无法匹配的情况下
照样返回 **P = 0.111**，而那个数被写进了 R 包 README。**该数字已撤回。**

旧预注册（`step103_density_matched.py`）按"记录数分位 × 基因数分位"匹配，
得 **3.44 倍、P = 0.041**；两套实现匹配的是不同的东西，不能互相引用。

---

## 1. 估计目标（须冻结的七项）

| 项 | 决定 | 理由 |
|---|---|---|
| **1.1 归属口径** | `any_record` 或 `lead_variant`，**不得用 `significant_records`** | 背景位点没有显著记录，无法与观测同口径打分。`significant_records` 仅保留为复现已发表数字的 legacy 口径 |
| **1.2 匹配变量** | `n_records`、`span`、`n_genes` **三者全用** | 只匹配记录数不构成"控制基因密度"；`span` 是唯一能捕捉串联的变量 |
| **1.3 容差** | **待定**——见 §2，必须在看结果前定 | 这是能翻转结论的那个参数 |
| **1.4 染色体** | 默认**不**按染色体分层 | 分层会使可匹配池急剧缩小；若分层则须同时放宽容差，两者不能各自独立选 |
| **1.5 排除显著位点** | 候选池**排除**全部显著位点 | 否则零分布被观测本身污染 |
| **1.6 抽样** | 一次抽样内**不放回**；池耗尽则该次抽样作废并计数 | 放回会悄悄收窄零分布 |
| **1.7 最低匹配覆盖率** | **100%**。达不到则返回 NA 与失败原因，不出 P 值 | 部分匹配算出的 P 不是所声明的检验 |

§1.1、1.2、1.4–1.7 **本文件即为冻结**；§1.3 待定。

---

## 2. 容差怎么定（三条路，须选一条并写明）

**不得**在看过各容差的 P 之后再选。三条可事先论证的路径：

- **A. 按覆盖率定**：取**能使匹配覆盖率达到 100% 的最小容差**。
  在 CD4 格上是 0.50。优点：规则与结果无关，可事先写死；
  缺点：不同格子会得到不同容差，跨格不可比。
- **B. 固定一个值并报敏感性**：取 1.00（对数尺度上约 2.7 倍），
  **同时报 §0 的整张扫描表**，正文写"结论在覆盖率合格的全部容差下一致"。
- **C. 改用分层而非连续容差**：按 `n_records`、`span`、`n_genes` 的
  三分位/四分位分层精确匹配，无容差参数。
  与旧预注册 `step103` 的做法一致，代价是分层内可能无候选。

**建议 B**：它把不稳定性**报出来**而不是靠选参数掩盖，
且在本数据上覆盖率合格的三个容差（0.50/1.00/2.00）P 值一致（0.022/0.042/0.040），
结论不依赖具体取值。

⚠ 若选 B，正文措辞必须是"在覆盖率合格的容差范围内 P 介于 0.022–0.042"，
**不得只引其中一个**。

---

## 3. 判读表（在看结果前写死）

| 情形 | 判读 |
|---|---|
| 覆盖率合格的全部容差下 P < 0.05 | 富集**不能**由位点大小/记录数/基因数解释 |
| 全部 P ≥ 0.05 | 富集**可以**由密度解释；归属主张须降级为描述性 |
| P 跨 0.05 分界 | **该检验未识别出估计目标**，不得引用任一 P 值，只报扫描表 |
| 无容差能达到 100% 覆盖 | 该格**无法**做密度匹配；如实报告"做不成"，不得退回部分匹配 |

---

## 4. 与旧分析的关系

`step103_density_matched.py` 的 3.44 倍 / P = 0.041 **不撤回**，但须写明：

- 它按分位数分层匹配，与本预注册的连续容差**不是同一个检验**；
- 两者都只覆盖 melanoma-meta 与 HCC 两格，未覆盖 RA 与 eQTLGen；
- 正文**不得**把两者当作"同一结果的两次计算"。

冻结本预注册后，须在**同一套修正分区**上重跑两者并并列报告。

---

## 5. 冻结前不得做的事

1. 不得在正文引用任何单一置换 P 值；
2. 不得把 R 包 README 与正文的数字当作同一结果（**已撤回 README 的那个数**）；
3. 不得在位点分区问题（见 `CONVENTION_REVIEW_PACKET.md`）解决前冻结本文件——
   置换是在位点上做的，位点定义未定则估计目标也未定。
