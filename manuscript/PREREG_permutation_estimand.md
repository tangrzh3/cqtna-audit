## 1. 估计目标（须冻结的七项）

| 项 | 决定 | 理由 |
|---|---|---|
| **1.1 归属口径** | `any_record` 或 `lead_variant`，**不得用 `significant_records`** | 背景位点没有显著记录，无法与观测同口径打分。`significant_records` 仅保留为复现已发表数字的 legacy 口径 |
| **1.2 匹配变量** | `n_records`、`span`、`n_genes` **三者全用** | 只匹配记录数不构成"控制基因密度"；`span` 是唯一能捕捉串联的变量 |
| **1.3 容差** | **待定**——见 §2，必须在看结果前定 | 这是能翻转结论的那个参数 |
| **1.4 染色体** | 默认**不**按染色体分层 | 分层会使可匹配池急剧缩小；若分层则须同时放宽容差，两者不能各自独立选 |
| **1.5 排除显著位点** | 候选池**排除**全部显著位点 | 否则零分布被观测本身污染 |
| **1.6 抽样** | 一次抽样内**不放回**；池耗尽则该次抽样作废并计数 | 放回会悄悄收窄零分布 |
| **1.6b 抽样算法的名称** | **randomized-greedy matching**（规范排序 + 每次置换随机化目标顺序的贪心不放回匹配）| **不是**从全部可行完整匹配中均匀抽样；见 S38-A1 §6.2b。名称必须如实写出 |
| **1.7 最低匹配覆盖率** | **100%**。达不到则返回 NA 与失败原因，不出 P 值 | 部分匹配算出的 P 不是所声明的检验 |

§1.1、1.2、1.4–1.7 **本文件即为冻结**；§1.3 待定。

## 2. 容差怎么定（三条路，须选一条并写明）

**不得**在看过各容差的 P 之后再选。三条可事先论证的路径：

- **A. 按覆盖率定**：取**能使匹配覆盖率达到 100% 的最小容差**。
  在 CD4 格上是 0.50。优点：规则与结果无关，可事先写死；
  缺点：不同格子会得到不同容差，跨格不可比。
- **B. 固定一个值并报敏感性**：取 1.00（对数尺度上约 2.7 倍），
  **同时报 §0 的整张扫描表**，正文写"结论在覆盖率合格的全部容差下一致"。
- **C. 改用分层而非连续容差**：按 `n_records`、`span`、`n_genes` 的
  三分位/四分位分层精确匹配，无容差参数。
  与旧预注册 `step103` 的做法一致，代价是分层内可能无候选。

**建议 B**：它把不稳定性**报出来**而不是靠选参数掩盖，
且在本数据上覆盖率合格的三个容差（0.50/1.00/2.00）P 值一致（0.022/0.042/0.040），
结论不依赖具体取值。

⚠ 若选 B，正文措辞必须是"在覆盖率合格的容差范围内 P 介于 0.022–0.042"，
**不得只引其中一个**。

## 3. 判读表（在看结果前写死）

| 情形 | 判读 |
|---|---|
| 覆盖率合格的全部容差下 P < 0.05 | 富集**在本匹配规则下**未被位点大小/记录数/基因数构成的零分布解释掉 |
| 全部 P ≥ 0.05 | 富集**未通过**本密度零分布；归属主张须降级为描述性 |
| P 跨 0.05 分界 | **该检验未识别出估计目标**，不得引用任一 P 值，只报扫描表 |
| 无容差能达到 100% 覆盖 | 该格**无法**做密度匹配；如实报告"做不成"，不得退回部分匹配 |

### 7.3 覆盖率不足的记录（§1.7 的实际触发情况）

容差 0.10 在四个格子上不合格：RA × CD4 **43.9%**、HCC-low × CD4 **50.0%**、
melanoma × CD4 **75.0%**、melanoma × eQTLGen **97.1%**；

**这些格返回 NA 而不是 P 值，正是本文件 §1.7 要求的行为。**
⚠ 若日后有人在 README 或正文里看到容差 0.10 的 P 值，那一定是绕过了 §1.7。

### 7.4 与 §4 的关系（不得混引）

`step103` 的 3.44× / P = 0.041 按**分位分层**匹配，与本文件的连续容差匹配不是同一个检验，
**不撤回但不得并列为"同一结果的两次计算"**。
在修正分区 + 本估计目标下，melanoma × CD4 的密度匹配倍数为 **4.87×**，
与其未匹配归属倍数 4.96× 接近——即**在本匹配规则与本分区下，密度匹配不再产生实质衰减**。
⚠ 这**不能**写成"旧的衰减是假的"，也**不能**写成"密度不解释这个富集"——
只能写成"在所指定的密度零分布下，富集依然存在"。
⚠ **密度置换与疾病名单错配检验的是两个不同的问题**，前者不能替后者背书（复核者指出）。
