## 5. 为什么任何一格都不改变判定（这一节是全文件的要害）

TPI1 的靶点主张是在这五处垮的：

1. FDR = 0.119（名义显著，非解决）；
2. PP.H4 = 0.51，16 个 window × prior 组合中仅 8 个通过（先验依赖）；
3. 该区域结局 GWAS **无法精细定位**；
4. chr12p13 的基因归属**遗传学未解决**；
5. 区室归属：TPI1 在恶性细胞中比工具变量来源的 CD4⁺T 高 **2.75 log₂，16/16 患者**。

**CD4⁺T 细胞里的敲低实验对 1–5 一条都不触及。** 它回答的是"这个基因在这个细胞类型里
做不做事"——而那**从来不是垮掉的那一级**。

**禁止条款**：无论结果如何，正文与补充材料中**不得**出现形如
"TPI1 has functional consequences in CD4⁺ T cells" 的句子作为**支持性**证据。
这句话即使为真也与本文的判定无关，而读者只会把它读成我们在给自己的否定判决松口。

### 6.3 为什么是 C 而不是 A：决定性的是对照臂，不是扰动臂

TPI1 的四条 guide 记录一致显示：

```
target expr 0.000 in 91 cells | NTC expr 0.000 in 313,989 cells | t = 0.00 | signif_knockdown = False
```

**非靶向对照细胞里 TPI1 的表达也是 0。** 这不是"敲低失败"，而是
**该测定根本不测这个基因**——因此 on-target 敲低无从核验。
与之一致的还有 DE 表里的 `target_baseMean = NaN`、`low_target_gex = True`、
`n_guides = 1`（`single_guide_estimate = True`，故 guide 间相关性这道质控也做不了）。

这不是 TPI1 独有：**12,604 个被扰动基因里有 601 个（4.8%）的全部 guide 在对照臂表达为 0**；
在可测下游基因集合里，**GAPDH、ALDOA、LDHA 同样缺席**，而 PGK1、ENO1、PKM、HK1、
STAT3、IRF4、ACTB 在。缺席的几个都属于表达量最高的一类基因，
这与探针式测定的面板构成有关；**本文件不对机制作进一步推断**。

⚠ **只看 DE 那一列的人会把它读成 outcome A**：82 和 198 个 DE 基因分别位于第 90、94 百分位。
但在 on-target 不可核验、单 guide、细胞回收第 3 百分位的条件下，
**这些 DE 基因无法归因于 TPI1 敲低**。
这正是本项目技术坑 §四-58 的同一形态：**一个不报错的流程，输出的可能不是你以为的那个。**
